Control de la sesión

Reiniciar cierra Chromium y las apps abiertas; el perfil y las pestañas se conservan.

Cómo usar el escritorio en el iPhone
  • Abrir: pulsa «Abrir escritorio». Si es la primera vez, espera unos segundos mientras arranca XFCE.
  • Teclado: usa el botón de teclado del panel de KasmVNC (abajo a la derecha) para escribir acentos y símbolos.
  • Toque: un toque equivale a clic; arrastra para desplazarte; pellizca para acercar si el cliente lo permite.
  • Portapapeles: usa el panel de portapapeles de KasmVNC. Safari exige un toque para pegar.
  • Pantalla completa: botón ⛶ del visor, o «Añadir a pantalla de inicio» desde Compartir en Safari.
